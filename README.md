# CV Application

A simple CV builder built with React and Vite, created as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

Fill in your details, submit each section to see it displayed as plain text, and click Edit to change it again.

## Features

- **General Information:** name, email and phone number
- **Education:** school name, title of study and date of study
- **Experience:** company name, position title, main responsibilities, and from/until dates
- **Submit and Edit:** each section switches between a form and a display view, and the inputs come back pre-filled when you edit

## Built With

- [React](https://react.dev/)
- [Vite](https://vite.dev/)
- Plain CSS
